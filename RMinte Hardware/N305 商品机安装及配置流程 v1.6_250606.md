## 2.安装Docker

### Install using the apt repository:

```# Add Docker's official GPG key:
sudo apt-get update
sudo apt-get install ca-certificates curl
sudo install -m 0755 -d /etc/apt/keyrings
sudo curl -fsSL https://download.docker.com/linux/ubuntu/gpg -o /etc/apt/keyrings/docker.asc
sudo chmod a+r /etc/apt/keyrings/docker.asc

# Add the repository to Apt sources:
echo \
  "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.asc] https://download.docker.com/linux/ubuntu \
  $(. /etc/os-release && echo "${UBUNTU_CODENAME:-$VERSION_CODENAME}") stable" | \
  sudo tee /etc/apt/sources.list.d/docker.list > /dev/null
sudo apt-get update
```

### To install the latest version, run:

`sudo apt-get install docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin`

## 11.安装Prometheus（**非常重要**）

### 创建文件夹
```
mkdir prometheus

cd prometheus
```

### 创建 Docker Compose 文件
`nano docker-compose.yml`

复制以下内容：

```
services:
  prometheus:
    image: prom/prometheus:latest
    container_name: prometheus
    ports:
      - "9090:9090"
    volumes:
      - ./prometheus.yml:/etc/prometheus/prometheus.yml
      - prometheus_data:/prometheus
    command:
      - '--config.file=/etc/prometheus/prometheus.yml'
      - '--storage.tsdb.path=/prometheus'
      - '--web.enable-lifecycle'
    restart: unless-stopped
    networks:
      - monitoring

volumes:
  prometheus_data:
    name: prometheus_data

networks:
  monitoring:
    driver: bridge
```

`Crtl+X`后键入`Y`回车保存退出

再创建一个

`nano prometheus.yml`

复制以下内容：

```
global:
  scrape_interval: 15s
  evaluation_interval: 15s

scrape_configs:
  - job_name: 'prometheus'
    static_configs:
      - targets: ['localhost:9090']
```
`Crtl+X`后键入`Y`回车保存退出

### 拉起并运行

`sudo docker compose up -d`

### 退回根目录

`cd ~`

## 12.安装TEI

### 更新系统并安装基础依赖

```
sudo apt update
sudo apt install -y gpg-agent wget build-essential libssl-dev pkg-config protobuf-compiler gcc libonnxruntime-dev
```

### 验证 GCC 安装

`gcc --version`

### 预期输出类似：

`gcc (Ubuntu 11.4.0-1ubuntu1~22.04) 11.4.0`

### （可选）安装 MKL 或 OpenBLAS

---

#### 安装 Intel MKL

```
wget -O- https://apt.repos.intel.com/intel-gpg-keys/GPG-PUB-KEY-INTEL-SW-PRODUCTS.PUB | gpg --dearmor | sudo tee /usr/share/keyrings/oneapi-archive-keyring.gpg > /dev/null
echo "deb [signed-by=/usr/share/keyrings/oneapi-archive-keyring.gpg] https://apt.repos.intel.com/oneapi all main" | sudo tee /etc/apt/sources.list.d/oneAPI.list
sudo apt update
sudo apt install -y intel-oneapi-mkl intel-oneapi-mkl-devel
```

#### 配置 MKL 环境变量

```
echo 'export LD_LIBRARY_PATH=/opt/intel/oneapi/compiler/2025.1/lib:/opt/intel/oneapi/mkl/2025.1/lib/intel64:$LD_LIBRARY_PATH' >> ~/.bashrc
source ~/.bashrc
```

---

#### 或者安装 OpenBLAS

`sudo apt install -y libopenblas-dev`

---

### 清理现有 Rust 安装

```
# 卸载 Snap 安装的 Rust 和 Rustup
sudo snap remove rust rustup

# 卸载系统包管理器的 Rust（如果存在）
sudo apt remove -y rustc
sudo apt autoremove -y

# 清理 Rustup 和 Cargo 的用户目录
rm -rf ~/.rustup ~/.cargo
```

### 安装官方 Rustup

`curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh -s -- -y`

#### 配置 PATH 确保 ~/.cargo/bin 在 PATH 中：

```
echo 'export PATH="$HOME/.cargo/bin:$PATH"' >> ~/.bashrc
source ~/.bashrc
```

#### 验证 Rust 安装 检查 Rust 和 Cargo 版本：

```
rustc --version
cargo --version
rustup --version
```

#### 预期输出类似：

```
rustc 1.87.0 (17067e9ac 2025-05-09)
cargo 1.87.0 (17067e9ac 2025-05-09)
rustup 1.x.x (具体版本号)
```

### 更新 Rust 工具链

`rustup update`

### 克隆 TEI 仓库

```
git clone https://github.com/huggingface/text-embeddings-inference
cd text-embeddings-inference
```

### 安装 pkg-config

```
sudo apt update
sudo apt install -y pkg-config
```

### 确保 OpenSSL 开发库已安装

`sudo apt install -y libssl-dev`

### 安装 TEI

#### 进入 router 目录：
`cd router`

#### 更新依赖

`cargo update`

---

#### 使用 MKL 构建

`cargo install --path router --features mkl`

---

#### (或者)使用 ONNX Runtime（ORT）构建

`cargo install --path router --features ort`

---

**注意：** router 是 TEI 项目中的子目录，确保在 `text-embeddings-inference/router` 目录下运行 `cargo install`。如果当前不在 router 目录，切换到正确路径：`cd router`

### 编译 TEI

`cargo build --no-default-features --features "candle,http,static-linking" --release`

### 验证 TEI 安装

`./target/release/text-embeddings-router --version`

#### 预期输出类似：

`text-embeddings-router 0.x.x`

### 启动 TEI 服务

#### 启动嵌入模型

`./target/release/text-embeddings-router --model-id /home/rm01/models/embedding/bce_v1 --port 58180 --hostname 0.0.0.0 --prometheus-port 9180`

#### 测试嵌入模型：

`curl 127.0.0.1:58180/embed -X POST -d '{"inputs":"What is Deep Learning?"}' -H 'Content-Type: application/json'`

#### 启动重排模型

`./target/release/text-embeddings-router --model-id /home/rm01/models/reranker/bce_v1 --port 58181 --hostname 0.0.0.0 --prometheus-port 9181`

#### 测试重排模型：

`curl 127.0.0.1:58181/rerank -X POST -d '{"query": "What is Deep Learning?", "texts": ["Deep Learning is not...", "Deep learning is..."]}' -H 'Content-Type: application/json'`
