# N305 商品机镜像刷写流程

## 准备工作

1. 将启动盘接入USB Hub，并将Hub（参考标签方向）插入主板名为`N100_USB`的USB-C口，链接电源启动主板
2. 将系统更改启动顺序从启动盘启动，并选择Try Ubuntu（试用Ubuntu）
3. 进入系统后接入存储卡和读卡器
4. 挂载硬盘（存储卡）

---

## 使用镜像装机

`Crtl+Alt+T`

### 确认镜像文件完整性：
ls -lh /media/ubuntu/N305_RM01/N305_0606.img

### 准备目标电脑 / 连接目标电脑的磁盘（例如 /dev/sdb 或 /dev/nvme0n1）/ 确认磁盘设备名称：
lsblk

### 卸载目标磁盘的所有分区：
sudo umount /dev/mmcblk0p*

## 使用 dd 将镜像写入目标磁盘：
sudo dd if=/media/ubuntu/N305_RM01/N305_0606.img of=/dev/mmcblk0 bs=64K status=progress
